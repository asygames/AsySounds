# AsySounds v0.1.4 — Voice-first impact cleanup

## What changed
- Five synchronized 5-second A/B recordings now isolate the stages: original microphone, neural-only, after residual VAD, after impact suppression, and final voice processing.
- The RNNoise / impact distinction is no longer conflated in one clip. Each stage has a manually downloadable WAV for listening to the exact same utterance.
- Normal neural strength (up to 85%) no longer adds a VAD amplitude gate, which could modulate quiet vowels at 100 Hz; above 85%, residual attenuation is deliberately mild.
- The impact detector protects breathy/fricative speech (s, sh, f), requires a stronger broadband transient before whole-frame ducking, and reduces the depth/duration of ducking when a clap overlaps speech. Sparse clicks still receive local suppression.
- The default impact slider for new settings is 45% instead of 85%. Previously saved settings are preserved; users can select Voice-first or set impact to 0% for a controlled comparison.

## Fixes & validation
- Added regression tests for speech-like fricatives, breath-like broadband sound, VAD/impact isolation, and previously supported isolated click/clap processing.
- Build and tests: Rust formatting, unit tests, Clippy, Tauri unit tests, and production frontend. The portable Windows package includes the correct production WebView assets and WebView2 loader when required.
- No changes to default Windows audio endpoints, Sonar settings, or driver installation.

## Compatibility and limits
- Windows x64, WebView2 required. Virtual microphone routing still requires an existing VB-CABLE-compatible driver.
- This is a voice-fidelity-oriented tradeoff. Strong claps overlapping speech cannot be cleanly removed with this transient detector; it prioritizes retaining syllables rather than hard-muting them.
- The user-reported buzz is localized to the VAD/impact stages, but an actual recording is needed to establish whether the update resolves it on the user's microphone. Screenshot-only RMS values cannot prove audio quality.
- No automatic WAV saving or upload; files remain in memory until the user chooses Save WAV.
