# AsySounds v0.1.1 — Processed microphone routing (Windows)

## New
- Dedicated **Headphone preview** and **Virtual cable output** modes in the Microphone studio.
- Detects paired VB-CABLE playback and recording endpoints, and shows the matching recording device to select in OBS or Discord.
- Explicit start/stop for the processed route. Routing never automatically starts when the app opens.
- Five-second same-input A/B diagnostics report average and peak levels in dBFS, and temporarily silence AsySounds output while recording.

## Fixes and safety
- Blocks cable mode when no matching capture endpoint is available, preventing silent fallback to speakers.
- Rejects routing a cable's recording endpoint back into itself (feedback-loop prevention).
- Independent output mute retains active capture, neural filtering and diagnostics.
- Windows default devices, Sonar configuration, and hardware drivers are not changed automatically.
- Windows executable uses GUI subsystem; normal application launch does not open a CMD console.

## Technical
- Local Rust RNNoise-derived DSP at 48 kHz with bounded audio buffers.
- Core tests, Clippy, Tauri checks and React build are validated in the Windows build workflow.
- Portable x64 package includes the application, license and third-party attribution.

## Compatibility and setup
- Windows x64; WebView2 runtime is required.
- **Requires an existing VB-CABLE-compatible driver for virtual microphone routing.** The application does not install or ship a driver.
- Send processed audio to **CABLE Input** (playback); select matching **CABLE Output** (recording) as the input in Discord or OBS.
- Without the driver, headphone preview remains available. No Linux build is provided for this Windows Core Audio prototype.

## Known limitations
- Real-device microphone quality and long-session latency still need testing; reduction of simultaneous speech and impacts is not guaranteed.
- Cable mode currently uses a single selected output; simultaneous headphone monitoring and cable output are not yet supported.
- Game/Chat/Media/Aux channel strips are visual prototypes, not a complete Sonar replacement or proprietary virtual audio driver.
