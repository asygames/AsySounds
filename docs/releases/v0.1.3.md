# AsySounds v0.1.3 — Voice quality diagnostics and smoother attenuation

## New
- Four synchronized five-second A/B tracks: Original microphone, neural-only RNNoise blend, neural + residual gate/impact control, and final compressor/EQ.
- Each WAV may be saved manually for troubleshooting. Audio is kept in memory; there are no automatic disk writes or uploads.
- Each stage's average level is displayed relative to the original.
- A visible **Voice-first preset** reduces processing aggressiveness and makeup gain without changing Windows defaults.

## Fixes
- Smooth residual VAD attenuation sample-by-sample across 10-ms frame boundaries to avoid abrupt periodic gain steps.
- Smooth impact-filter attack/release rather than applying a different fixed gain to whole adjacent frames.
- Preserve fast transient attack and local-click suppression while reducing release pumping.
- Added a regression test for inter-frame gain discontinuities.

## Validation and limits
- Core unit tests, Rust formatting/Clippy, Tauri unit tests and React build are checked during release creation.
- A/B tracks share a 48 kHz timeline and isolate where voice degradation is introduced.
- A screenshot and dB levels cannot confirm the cause of the audible buzz. Compare stage 2 to 1, stage 3 to 2, and stage 4 to 3; use the conservative preset if the full chain distorts speech.
- Real microphone listening and device-to-application latency still require live validation. This release does not guarantee complete click/clap removal.

## Compatibility
- Windows x64; WebView2 required. Existing VB-CABLE-compatible driver needed only for virtual-microphone routing.
- No driver installation or Windows/Sonar default-device changes. GUI executable opens without a console.
- AsySounds is still a prototype; virtual mixer channels are not a complete Sonar replacement.
